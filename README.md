### COMMANDS USED

-   php artisan make:component layout --view // Create a new view component
-   php artisan db:wipe // Drop all the tables and have empty database
-   php artisan migrate // Run the database migrations
-   php artisan migrate:fresh // Drop all tables and create a new migration
-   php artisan migrate:rollback // Rollback the last database migration or undo the last action
-   php artisan make:controller AuthController // Create a new controller class
